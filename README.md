## 📐 高中数学精讲专栏（沪教版同步全体系）

严格依据**上海高中数学教材（沪教版）编排顺序**与**上海高考数学学情考法特点**，全系列覆盖高一至高三必修与选择性必修全部 5 大册核心专题。全系列均采用 **`new_know`** 认知解构方法，涵盖“前置诊断矩阵、痛点溯源、核心机制、四阶段攻坚路线、Python 科学计算仿真与高考考法模型”六维闭环。

### 📘 必修第一册（高一上：集合与逻辑、等式与不等式、函数性质与幂指对）
- 📦 **[集合与常用逻辑用语深度解析](blog/highschool-sets-and-logic-guide.md)**  
  从消除自然语言歧义的集合论痛点溯源、三大特性与互异性防坑，到交并补德·摩根律、充分必要条件“小推大”集合化降维映射与计算机布尔搜索实战。对应上海高考填空第 1 题与选择第 13 题。
- ⚖️ **[等式、不等式与基本不等式最值模型深度解析](blog/highschool-inequalities-guide.md)**  
  从非等式约束与最优化现实痛点、赵爽弦图面积无字证明，到均值定理“一正二定三相等”三大铁律、“1的代换”配凑绝技、工业包装材料最小化与 Python 科学计算最优化。对应上海高考填空第 2/8 题及解答题约束转化。
- 🌋 **[函数概念、幂指对函数性质与增长模型深度解析](blog/highschool-power-exp-log-functions-guide.md)**  
  从宇宙极端尺度与人类对数神经感知、指数爆炸 vs 对数漫步终极增长大对决，到互为反函数几何对角镜像、换底公式推论神器与碳-14 考古年代测定仿真。对应上海高考选择第 14 题与综合建模。

### 📗 必修第二册（高一下：三角比与三角函数、平面向量与复数）
- 📐 **[三角比、三角函数与解三角形建模深度解析](blog/highschool-trigonometry-guide.md)**  
  从直角三角比到单位圆任意角几何投影，正弦定理“外接圆直径”、余弦定理“勾股定理推广与数量积”、到上海高考真实“双杆影子测量模型”几何测距及 Python 数值仿真。对应上海高考填空第 5/11 题。
- 🧭 **[平面向量、数量积与动态极值转化深度解析](blog/highschool-vectors-guide.md)**  
  从物理“位移与力”到几何“有向线段”、代数“坐标行阵”的三位一体；基底分解与坐标运算、极化恒等式与动点几何投影转化、上海高考模长最值压轴题剖析，以及 3D 图形学光照着色 Python 仿真。对应上海高考填空第 12 题压轴。
- 🔮 **[复数几何意义、平面向量同构与模长距离度量深度解析](blog/highschool-complex-numbers-guide.md)**  
  从一维数轴崩溃痛点溯源、虚数单位 $i$ 作为 90 度正交旋转算子本质，到高斯复平面点/向量映射同构、复数乘法“模长相乘辐角相加”升维飞跃，再到复数模长两点距离四大高考几何轨迹模型（圆、中垂线、阿氏圆、椭圆）及 Python 3 原生复数旋转仿真。对应上海高考填空第 2~4 题及模长最值几何综合。

### 📙 选择性必修第一册（高二上：立体几何、空间向量与平面解析几何）
- 🧊 **[空间几何体、立体几何与空间向量模型深度解析](blog/highschool-solid-geometry-guide.md)**  
  从“辅助线玄学”到三维笛卡尔直角坐标系建立，线面垂直/平行判定公理化证明、法向量求解流水线，异面直线角、线面角与二面角统一向量公式，点到平面投影距离，以及 3D 图形学光线追踪漫反射着色 Python 仿真。对应上海高考填空第 9 题与解答第 18 题大题（14分）。
- 🎯 **[平面解析几何与圆锥曲线综合探究深度解析](blog/highschool-conic-sections-guide.md)**  
  从椭圆、双曲线、抛物线几何统一定义，到“设而不求”联立韦达消元黄金四步法、弦长公式与点差法中点弦技巧、定点定值与垂直最值模型剖析，以及开普勒行星轨道与引力弹弓 Python 天体仿真。对应上海高考填空第 7/15 题与解答第 19 题压轴大题（14分）。

### 📕 选择性必修第二册（高二下：数列与数学归纳法、导数及其应用）
- 🔢 **[数列通项求和、数学归纳法与递推创新深度解析](blog/highschool-sequences-induction-guide.md)**

- 📈 **[导数及其应用、函数单调性与极值点偏移深度解析](blog/highschool-derivatives-guide.md)**  
  从静态代数到无穷小切线斜率微积分飞跃、常见初等函数导数法则、参数分类讨论防漏解模板、隐零点设而不求整体代换、极值点偏移对称构造法、指对切线经典放缩，以及深度学习梯度下降最优化 Python 仿真。对应上海高考解答第 20 题压轴大题（16分）。
