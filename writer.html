此写作台直接对接 GitHub REST API。请输入博主本人的 GitHub 个人访问令牌 (Personal Access Token)，验证通过后即可在线向仓库发布文章。

💡 30 秒获取 Token 指引：
1. 访问 GitHub Token 新增页面 ↗；
2. Note 填写 Inkstar Writer，勾选 repo（完全读写仓库权限）；
3. 点击页面最下方 Generate token，复制粘贴至上方即可。
* 密钥仅保存在当前设备浏览器的 localStorage 中，绝不经过任何第三方服务器。
