匀变速直线运动五大基本公式体系 高频必背

五个物理量：初速度 $v_0$、末速度 $v$、加速度 $a$、时间 $t$、位移 $x$。每个公式包含其中4个量，缺少1个量。解题时“缺谁不用谁”！

① 速度-时间公式 不含位移 $x$
$$v = v_0 + at$$

物理意义：末速度等于初速度加上这一段时间内的速度增量 $\Delta v = at$。

② 位移-时间公式 不含末速度 $v$
$$x = v_0 t + \frac{1}{2} a t^2$$

几何来源：$v-t$ 图形中矩形面积 $v_0 t$ 与三角形面积 $\frac{1}{2}at^2$ 之和。

③ 速度-位移公式 不含时间 $t$
$$v^2 - v_0^2 = 2ax$$

解题秘籍：题干若未提及时间 $t$ 且不求时间 $t$ 时，首选此公式！结合动能定理 $W = \Delta E_k$ 亦可推导。

④ 平均速度位移公式 不含加速度 $a$
$$x = \bar{v} t = \frac{v_0 + v}{2} t$$

关键性质：匀变速运动的平均速度刚好等于初末速度的算术平均值。

⑤ 逆向位移公式 不含初速度 $v_0$
$$x = vt - \frac{1}{2} a t^2$$

妙用场景：刹车至静止（末速 $v=0$）的逆向思维法，等效于初速为0的匀加速运动！

矢量正负号定则
  • • 公式中 $v_0, v, a, x$ 均为矢量。
  • • 先定正方向：通常以初速度 $v_0$ 方向为正方向。
  • • 加速：$a$ 与 $v_0$ 同向，代入正值 $a > 0$。
  • • 减速：$a$ 与 $v_0$ 反向，代入负值 $a < 0$。

性质一 · 极值与不等式

时间中点速度 $v_{t/2}$ 与 位移中点速度 $v_{x/2}$ 对比

恒有：$v_{x/2} > v_{t/2}$ (当 $a \neq 0$)
时间中点瞬时速度： 算术平均数
$$v_{\frac{t}{2}} = \bar{v} = \frac{v_0 + v}{2}$$
匀变速直线运动中，时间中点的瞬时速度恒等于全程的平均速度！
位移中点瞬时速度： 平方平均数 (均方根)
$$v_{\frac{x}{2}} = \sqrt{\frac{v_0^2 + v^2}{2}}$$
由前半程 $v_{x/2}^2 - v_0^2 = 2a\frac{x}{2}$ 与后半程 $v^2 - v_{x/2}^2 = 2a\frac{x}{2}$ 联立消去 $ax$ 立即推得。
不等式数学证明： $$v_{\frac{x}{2}}^2 - v_{\frac{t}{2}}^2 = \frac{v_0^2 + v^2}{2} - \left(\frac{v_0+v}{2}\right)^2 = \frac{(v - v_0)^2}{4}$$ 因为 $(v - v_0)^2 > 0$（当 $a \neq 0$ 时），故不论是匀加速还是匀减速，恒有 $v_{\frac{x}{2}} > v_{\frac{t}{2}}$！

连续相等时间位移差

$$\Delta x = x_{k+1} - x_k = aT^2$$

任意两个相邻且相等的时段内，位移增量恒等于常数 $aT^2$。这是判定物体是否做匀变速运动的铁律！

六段逐差法求加速度

$$a = \frac{(x_4+x_5+x_6) - (x_1+x_2+x_3)}{9T^2}$$

逐差法的巧妙之处：将纸带分为前后两组，最大限度减小测量偶然误差，所有测量数据均被有效利用。

瞬时速度求解公式

$$v_n = \frac{x_n + x_{n+1}}{2T}$$

利用“时间中点的瞬时速度等于这段时间的平均速度”，可精确求出某计数点的瞬时速度。

初速度为 0 的匀加速直线运动比例王国与几何切片

$v-t$ 图像面积分割图解 (梯形面积之比 $1:3:5:7$) 初速 $v_0 = 0$
几何奥秘：将大三角形按等时间 $T$ 剖切，依次得到 1 个小三角形、以及由小三角形组合而成的等高梯形。其面积比刚好构成奇数数列：$1 : 3 : 5 : 7 : \cdots : (2n-1)$！
1. 等时间末瞬时速度之比
$$v_1 : v_2 : v_3 : \cdots : v_n = 1 : 2 : 3 : \cdots : n$$
2. 前 1T、前 2T、前 3T 内累计位移之比
$$x_1 : x_2 : x_3 : \cdots : x_n = 1 : 4 : 9 : \cdots : n^2$$
3. 连续相等时间间隔内位移之比 (第1个T、第2个T...)
$$\Delta x_I : \Delta x_{II} : \Delta x_{III} : \cdots = 1 : 3 : 5 : \cdots : (2n-1)$$
4. 通过连续相等位移所需时间之比
$$t_I : t_{II} : t_{III} : \cdots = 1 : (\sqrt{2}-1) : (\sqrt{3}-\sqrt{2}) : \cdots : (\sqrt{n}-\sqrt{n-1})$$

经典力学模型 · 双体运动

追及与相遇问题：速度相等临界条件

模型一：速度大者减速追速度小者

典型情境：后车刹车匀减速，追赶前方匀速行驶的前车。

  • 若两车速度相等时，恰好后车在后方：永不相撞，此时两车相距最近。
  • 若两车速度相等时，后车恰好追上前车：恰好不相碰（临界安全状态）。
  • 若在速度相等之前就已经相遇：必定相撞（或相遇并超越）。
模型二：初速小者加速追初速大者

典型情境：后车从静止开始匀加速启动，追赶前方匀速行驶的前车。

  • 两车速度相等前：前车速度 > 后车速度，两车间距持续增大。
  • 两车速度相等瞬间：两车距离达到最大值！
  • 两车速度相等后：后车速度 > 前车速度，间距缩小，最终必定相遇并超越。
